# A Real-time 5G Macro-cells Signal Dataset for Signal Model Simulation and Prediction within Complex Terrain Areas

## Dataset Overview

This dataset contains UAV-based and ground-based 5G signal measurements collected in a mountainous urban environment in Chongqing, China. The dataset integrates signal observations, environmental variables, and base-station information for radio-propagation modeling and machine-learning research.

## Dataset Structure

raw_data/

* raw_datas.csv
* UAV and ground measurement records

grid_data/

* fishnet_30x30.csv
* Grid-based aggregated dataset

base_station/

* base_station_information.csv
* Anonymized base-station information

environmental_data/

* DEM
* NDVI
* Building features

## Coordinate Reference System

Grid center coordinates:
WGS 84 (EPSG:4326)

Projected layers:
WGS 84 / UTM Zone 48N (EPSG:32648)

## Data Collection Period

2025-05-23 to 2025-11-14
